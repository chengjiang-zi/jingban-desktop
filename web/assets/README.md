# 图标与素材来源

- `avatar-orb.png`：项目维护者提供的大肥鱼卡通头像，使用图像工具去除背景后用于悬浮球。原始卡通插画的具体作者与发布页尚待补充，不冒认其为本项目原创，也不将其归入代码 MIT 许可。
- `app.ico`：由同一头像制作的 Windows 应用图标。
- `public-icon.svg`、`public-icon.png`、`public-icon.ico`：本项目通用鲸鱼备用图标，适用项目 MIT 许可。

大肥鱼 Live2D 模型的原画及拆分为神宫凉子，建模为霓虹猫_NeonNeko，入口见 [作者发布视频](https://www.bilibili.com/video/BV1KmxY66EZ3/)。这份模型署名不等于已确认卡通头像由相同作者制作。

本次仅发布现有头像 PNG 与应用 ICO，不包含完整 Live2D 模型、贴图包、PSD 或参考声音。公开展示图标不意味着授予第三方任意商用、再授权或角色素材再分发权利；这些用途需自行核对原素材授权。若需要只使用项目自有图形，可删除本地头像覆盖文件并使用通用备用图标。
