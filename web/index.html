每一项能力，都可以替换。

本地服务由你运行；远程服务使用你自己的账户。保存后，新请求会使用新配置。

01 · 声音 / TTS
固定音色与语气

兼容接口需返回单声道 PCM16。当前 Breeze 模型按其非商用许可使用；替换服务不会自动改变素材许可。

02 · 对话与视觉

外部模式不调用这里的对话模型，也不注入鲸伴记忆。需外部智能体读取输入并返回回复。

使用流式 Chat Completions 格式。摄像头或屏幕可手动附加一帧；开启“随每次对话发送最新画面”后，每轮对话发送一张新图。

03 · 语音识别 / ASR

录音后上传到所配置的 /audio/transcriptions 接口。支持本地服务，当前不捆绑识别模型；每次录音最长 60 秒。

04 · 角色与桌面

依据已保存的去重记忆粗略估算，仅作互动参考。关闭只隐藏显示，不删除记忆。

显示开关立即生效；都隐藏后仍可从托盘恢复。

角色和 Core 由用户自行提供；更换后重载界面。当前只实现 Live2D 渲染，其他格式可扩展适配器。

05 · Mem0 高级设置（可选）

默认复用对话模型并在本机检索，无需另填。修改后先保存连接设置，再检查 Mem0。

自定义检索需要 /embeddings 接口；普通聊天模型不一定支持。更换检索配置会使用独立的记忆库，避免混用不同向量。

密钥不显示在页面回读中。

我的基础记忆

仅保存在本机；外部智能体模式不会读取这些记忆。聊天中使用“记住：…”可保存明确记忆，也可在这里添加。画面不会写入聊天记录。删除单条明确记忆不会删除包含相同内容的聊天记录；全部移除可使用“删除全部本地记忆”。

长对话会自动调用当前模型压缩旧上下文；原始记录仍保留。清空会话只删除聊天和摘要，不删除明确记忆。

本机控制接口

地址

认证：Authorization: Bearer <token>

令牌文件仅保存在本机，勿提交到 GitHub。

POST /v1/commands
{
  "requestId": "hello-001",
  "command": "speak",
  "text": "嘿，我已经住进你的桌面啦。"
}

返回任务 ID；接收成功不代表已经播完。

接口与边界

接口用途
GET /v1/capabilities查询实际能力
POST /v1/commands朗读、表情、气泡、任务状态、停止
GET /v1/state任务状态和播放状态
GET /v1/eventsSSE 事件与任务完成通知

MCP 接入

运行 integrations/mcp.mjs，提供能力查询、用户输入、呈现、状态与停止工具。DSH 配置参考 integrations/dsh.example.yml。

记忆只留一份

直接模式可使用本机基础记忆，重启后续聊；外部模式由智能体管理记忆，不注入本机记录。输入通过 companion_inputs 或 GET /v1/inputs?after=游标 读取；接入方需主动轮询或订阅 agent_input 事件，接口不会自动唤醒 DSH。
