每一项能力，都可以替换。

本地服务由你运行；远程服务使用你自己的账户。保存后，新请求会使用新配置。

01 · 声音 / TTS
固定音色与语气

兼容接口需返回单声道 PCM16。当前 Breeze 模型按其非商用许可使用；替换服务不会自动改变素材许可。

02 · 对话与视觉

DSH 模式使用主对话回复；经确认绑定的对话可共享鲸伴记忆。无需重复填写对话 API。

使用流式 Chat Completions 格式。摄像头或屏幕可手动附加一帧；开启“随每次对话发送最新画面”后，每轮对话发送一张新图。

03 · 语音识别 / ASR

录音后上传到所配置的 /audio/transcriptions 接口。支持本地服务，当前不捆绑识别模型；每次录音最长 60 秒。

04 · 角色与桌面

支持普通 Live2D 和 BongoCat 敲键盘角色；导入前先解压模型包；导入后请保留原文件夹的位置。

小鱼模型已内置。要显示它，请从 Live2D 官网取得 Cubism SDK for Web，在解压后的 Core 文件夹找到 live2dcubismcore.min.js；在下方选择该文件，再点击“重载角色”。下载及使用应遵循 Live2D 官方许可。官网：www.live2d.com/en/sdk/download/web/

支持 Live2D model3.json；角色库切换立即生效。BongoCat 模型需含左右手参数；Windows 下支持全局敲击互动。手动修改路径或 Core 后请重载界面。

05 · Mem0 高级设置（可选）

默认复用对话模型并在本机检索，无需另填。修改后先保存连接设置，再检查 Mem0。

自定义检索需要 /embeddings 接口；普通聊天模型不一定支持。更换检索配置会使用独立的记忆库，避免混用不同向量。

密钥不显示在页面回读中。

我的基础记忆

保存在本机；普通外部接口不读取记忆，经你确认绑定的 DSH 会话可检索共享笔记与摘要。聊天中使用“记住：…”可保存明确记忆，也可在这里添加。画面不会写入聊天记录。删除单条明确记忆不会删除包含相同内容的聊天记录；全部移除可使用“删除全部本地记忆”。

长对话会自动调用当前模型压缩旧上下文；原始记录仍保留。清空会话只删除聊天和摘要，不删除明确记忆。

桌宠与互动

试着对角色说「先歪头，再眨眼」。直连 API 自动附上动作说明，DSH 需要新版插件和已绑定会话。

默认关闭；开启后点击小鱼会轻拍并显示星星，不使用大肥鱼的触摸台词。键盘反馈不受影响。

仅在本机短暂显示对应键位，不记录输入历史；需要角色包提供对应键位素材。

依据已保存的去重记忆粗略估算，仅作互动参考。关闭只隐藏显示，不删除记忆。

显示开关立即生效；都隐藏后仍可从托盘恢复。

DSH 对话与共享记忆

在任意 DSH 会话中说“绑定鲸伴并共享记忆”，然后在这里确认。绑定后可检索共同记忆，新聊天会自动加入；主对话接收桌宠发出的消息，不需要另填对话 API。

只同步文字正文，不同步思考过程、工具输出或图片，不读取 API 配置密钥。已有聊天仅在你勾选后纳入，原会话不删除。基础模式按话题检索摘录，启用 Mem0 后还会整理用户发言（可能调用所配置的模型服务）。解除绑定停止后续共享，已贡献的记忆保留。

本机控制接口

地址

认证：Authorization: Bearer <token>

POST /v1/commands
{
  "requestId": "hello-001",
  "command": "speak",
  "text": "嘿，我已经住进你的桌面啦。"
}

返回任务 ID；接收成功不代表已经播完。

接口与边界

接口用途
GET /v1/capabilities查询实际能力
POST /v1/commands朗读、表情、气泡、任务状态、停止
GET /v1/state任务状态和播放状态
GET /v1/eventsSSE 事件与任务完成通知

MCP 接入

运行 integrations/mcp.mjs，提供能力查询、用户输入、呈现、状态与停止工具。DSH 配置参考 integrations/dsh.example.yml。

记忆只留一份
