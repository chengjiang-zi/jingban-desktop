鲸伴 0.2.0-beta.1 · 作者澄江子 · 免费开源

1. Windows 目录包请完整解压，再双击 jingban.exe；不要只复制 EXE。
2. 内置小鱼模型。请看 docs/MODELS-AND-SETUP.md，自行取得 Cubism Core，在连接设置选择 Core 并点击重载角色。
3. 对话可直接连接 API，或安装鲸伴 DSH 插件后绑定主会话。
4. 本地语音与识别服务需要自行准备。下载模型本身不会自动启动服务。
5. 敲键盘小鱼基于 BongoCat 模型资源修改；精确来源与修改范围见 THIRD_PARTY_NOTICES.md。
6. 演示所用模型链接和音色参数见 docs/DEMO-CONFIG.md。
