## 视频简介

我是澄江子。这次做的是「鲸伴」：把 Live2D、语音、画面理解、记忆和外部智能体接入整合成一个桌面应用。

可以切换直接 API 或 DSH 助手。可选 DSH 插件和软件放在同一个仓库，安装说明也准备好了。除了常规 Live2D，还有基于 BongoCat 素材修改的敲键盘小鱼模式；角色与服务都可以自行替换。

本次演示的角色渲染、TTS、ASR 和记忆存储/检索在本地运行；对话、画面理解与记忆整理使用配置的模型服务。切换服务后以你的实际配置为准。

这是 **Beta 测试版**，模型和服务需自行配置。视觉采用手动或逐轮附图，尚不是持续视频理解。软件代码免费开源；第三方模型和素材遵循各自许可，外部 API 可能收费。
