# 按演示配置鲸伴：给用户与 DSH 的入口

> 2026-11-02 分发范围更新：维护者已决定公开小鱼修改皮肤，源码中的 `bundled-models/DaFeiYu/` 含完整模型及来源说明，新构建将默认选择它；旧版 v0.2.0-beta.1 EXE 不因此自动更新。Live2D Core 仍需自行取得并在设置中选择；D 音色和语音权重仍不提供。历史版本的发布范围以对应版本说明为准。

这份说明用于让 DSH 根据公开文档协助配置。**可以复现主要功能，不保证完全相同的外观与声音。** 全程使用当前电脑的真实路径，不复制维护者电脑的目录、凭据或私人记忆。

## 哪些可以复现

| 项目 | 获取与配置 | 复现范围 |
|---|---|---|
| 普通大肥鱼 Live2D | 从 [演示配置](DEMO-CONFIG.md) 中的原作者入口取得完整包，导入 `.model3.json` | 可接入同一角色；动作效果还受模型包版本影响 |
| Cubism Core | 用户接受官方条款后取得 Core JS，在鲸伴中选择 | 不随程序提供 |
| 本地 TTS | Breeze v0.1.3 + Q8_0，启动服务，保存自己的音色 | 可复现本地发声及播放流程 |
| 演示 D 音色 | 参考 [声音方向与参数](DEMO-CONFIG.md) 自行生成、试听和保存 | 未公开声音文件，不能仅凭 ID、seed 还原相同声纹 |
| 语音识别 | faster-whisper + Whisper base，启动独立识别服务 | 可复现录音转文字流程，准确率受录音与设备影响 |
| 记忆 | 基础记忆，或在面板准备 BGE 并启用 Mem0 | 创建用户自己的记忆，不复制演示者的内容 |
| DSH 助手 | 可选插件、专用主会话、本机确认绑定 | 文字路由、共享记忆与自动朗读；自动桥接不含附图或连续通话 |
| 小鱼模式 | 可导入带 BongoCat 参数的合法自备模型 | 仓库 `bundled-models/DaFeiYu/` 已公开演示皮肤，鲸伴读取其中的场景适配 |
| 宣传片场景 | 视频里的文档及摄像头场景包含动画示意 | 不是可下载的软件功能预设或自动操作 Word 的流程 |

## 文件位置与实际填写值

以用户自选目录为例，不要求使用 D 盘：

```text
D:/AI/Jingban/
  app/                          # GitHub 下载的便携 EXE
  models/
    DeepSeek/                   # 原作者完整角色包，保留内部结构
      <实际名称>.model3.json
      <实际名称>.moc3
      ...贴图、动作、物理、表情...
    runtime/
      live2dcubismcore.min.js
  Breeze/
    runtime/                    # 上游运行时完整解压
    models/breeze-tts-2-q8_0.gguf
    voices/                     # Breeze 自己保存的音色资料
```

角色与 Core 从鲸伴文件选择器导入；复制到 EXE 旁不会自动完成配置。Breeze 的权重与 voices 属于语音服务，不是鲸伴模型目录。具体启动命令见 [模型安装指南](MODELS-AND-SETUP.md)。

| 配置项 | 演示约定 / 应填写内容 |
|---|---|
| 角色文件 | 当前电脑实际 `.model3.json` 绝对路径 |
| Core | 当前电脑实际 Core JS 绝对路径 |
| TTS 地址 | `http://127.0.0.1:8137`，Breeze 根地址 |
| 音色 ID | 当前 Breeze 服务里真实存在的已保存 ID，不照抄演示 ID |
| TTS 输出 | PCM16、单声道、24000 Hz |
| ASR 地址 | `http://127.0.0.1:61951/v1`，服务需单独启动 |
| ASR 模型名 | `faster-whisper-base` |
| 对话 | 选择 API 或 DSH；API 填提供方实际支持的地址、模型 ID 和 Key |
| 视觉 | 选支持图片的模型，并主动附图或开启逐轮附图 |
| 鲸伴外部接口 | 默认 `http://127.0.0.1:61950` |
| DSH tokenFile | 鲸伴“外部接入”页显示的真实令牌文件路径，不粘贴令牌内容 |

源码 `local-asr/setup.ps1` 默认将识别环境和模型放到仓库的 `.local/asr-venv/`、`.local/asr-model/`；普通便携 EXE 不会自动启动它。Mem0 检索模型放在**实际应用数据目录**下的 `embedding-models/`，数据库在 `mem0/`。直接运行便携版时，不要假设这些目录就在 EXE 旁；以界面和配置指南为准。

## 可直接交给 DSH 的配置请求

将仓库链接和下面这段话一起发给 DSH：

> 请帮我按 https://github.com/chengjiang-zi/jingban-desktop 配置鲸伴 Beta。先阅读 README、docs/REPRODUCE-DEMO.md、docs/MODELS-AND-SETUP.md、docs/DEMO-CONFIG.md；需要插件时再读 integrations/dsh-plugin/README.md。先检查我的系统、现有资源和服务，列出已找到的真实路径及缺失项，保留已有配置。按“程序启动→角色/Core→文字对话→TTS→ASR→图片→记忆→可选 DSH 插件”逐项配置和验收。需要我登录、提供密钥、取得模型或同意条款时告诉我；不要替我伪造音色 ID、会话 ID、授权或下载入口，不要把密钥、令牌和私人聊天发到仓库。插件使用专用会话，在鲸伴本机确认绑定；只修改 jingban 对应配置，不覆盖其他插件。演示 D 音色没有公开文件，小鱼皮肤可使用仓库 bundled-models/DaFeiYu，遇到未提供资源时请说明限制并让我选择替代资源。最后逐项报告通过、失败与未测试，不把服务启动等同于功能可用。

DSH 能否执行每一步还取决于其工具权限、电脑环境和网络；给一个链接不等于无人值守安装保证。不要自动接入不相关的历史会话。

## 验收顺序

1. 下载 EXE 与校验文件，核对 SHA-256；启动后检查版本与缺失配置提示。
2. 导入角色/Core，确认显示；检查跟随、触摸、取景及悬浮窗。
3. API 发一条测试消息；DSH 模式则先按插件文档验证专用主会话转发。
4. 在 Breeze 单独试听，再到鲸伴朗读；测试停止、播放方式和声音驱动嘴型。
5. 启动 ASR，录一段话确认转写；API 模式再测通话、打字和打断。
6. 先分享一张无隐私测试图，附图提问，核对模型是否确实识别。
7. 添加测试记忆，确认能检索，重启后复查，再删除测试内容。
8. 需要多会话共享时，逐个申请并在本机确认；检查未绑定会话不参与。

本机从 GitHub 下载版已验证首次空目录启动，以及接入已有资源后的普通角色显示、界面对话、TTS、ASR、图片理解和基础记忆。它不代表已经在新电脑上从零下载全部依赖，也不代表本轮重新验收了 DSH 安装、Mem0 迁移、小鱼导入或真人长通话。
