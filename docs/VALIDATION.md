## 本机验证

- Electron 开发版与 Windows 目录包已运行；桌宠、悬浮球、角色分开显示、鼠标跟随及连续点击反馈经过本机窗口检查。
- 本机配置的对话与图像 API 已完成实际请求验证；屏幕预览不等于自动发送画面，仍需主动附图或开启每次附图。
- 本地 Breeze 音色、流式/整句播放、停止后的音频和嘴型归零已实测。一次冷启动首段约 3.5 秒，热启动约 0.7 秒；仅为本机样本，不是性能承诺。
- Whisper base CPU 对一段约 7 秒参考录音转写约 1.9 秒，有个别误识别；不是准确率基准。
- Mem0 已使用真实 SDK 验证持久化、检索、编辑、删除、重启与迁移。打包版实际整理模型测试提取一条测试事实后清理。
- 自动测试覆盖鉴权、密钥隔离、配置、任务取消、语音打断、权限并发、音频调度、记忆删除保护、鼠标跟随、连续动作、窗口缩放与了解度。
- 了解度是去重事实数量的饱和估算，不衡量事实正确率或真实情感。手动确认事实权重为 1，自动事实为 0.5；分数为 round(100 × (1 − exp(−权重总和 / 20)))，上限 100。
