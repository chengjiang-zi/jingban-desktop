# 鲸伴 Beta 演示视频准备

建议标题：**[开源免费·Beta] 让大肥鱼住进桌面｜能聊天，也能陪你敲键盘**

作者澄江子，B站澄江子。先录真实功能，再剪辑成约 90 秒的演示；本文件是拍摄准备，不表示视频已录制或发布。

| 时长 | 画面 | 旁白要点 |
|---|---|---|
| 0–8 秒 | 桌面小鱼、键帽亮起、鼠标左右反馈 | “把聊天和桌宠整合到一个软件里，这是鲸伴。” |
| 8–22 秒 | 悬浮球拖动、气泡、切换角色 | “角色可以自己换，主界面和悬浮球都能操作。” |
| 22–40 秒 | 流式语音、嘴型、打字打断回复 | “可以聊天、朗读，也可以持续聆听；新的话可以打断旧回复。” |
| 40–54 秒 | 主动附加当前屏幕，再询问画面 | “使用支持图片的模型时，可以发送当前画面。这里还不是连续视频理解。” |
| 54–67 秒 | Mem0 查看、修改、删除一条测试记忆 | “长期记忆可选，也能交给外部智能体管理。” |
| 67–79 秒 | 连接设置、关闭键位反馈、开发者名单 | “角色、语音和对话服务都可以替换；这是整合与产品化项目。” |
| 79–90 秒 | Beta 提示与 GitHub 地址 | “作者澄江子，B站澄江子。软件代码开源免费，现在是 Beta，欢迎测试和反馈。” |

录制前使用单独测试数据：虚构聊天、测试记忆、无个人文件的桌面。不要展示 API 密钥、集成令牌、私人聊天或用户目录。素材来源和模型许可放在视频简介；“开源免费”指本软件，外部 API 可能收费，模型不因此获得商用许可。

## 隐私与本次宣传片要求

不录整个桌面或 DSH 窗口。不出现桌面图标、任务栏、任何非演示 DSH 对话名称/正文、工作区名称、私人文件路径或密钥。只录鲸伴窗口；演示使用专用数据与虚构内容。共享记忆原理图标明示意，不能伪造真实对话截图。逐段检查素材后才加入视频。
