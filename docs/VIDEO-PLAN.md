场景之间使用多种约 1.5–1.8 秒的转场，暂停旁白并配短音效，给观众留出呼吸时间。字幕保持同一套蓝紫色样式，覆盖在完整画面下方，不通过缩小整个画面腾出字幕区。

## 素材性质

- 开场使用真实音色驱动嘴型。
- 跟随、触摸和小鱼键鼠反馈，是模拟输入驱动应用真实角色渲染的画布录制。
- 通话 UI 是明确标注的操作示意；摄像头为原创绘制画面，聊天内容为虚构演示，不冒充实际视觉识别结果。
- 写作与小鱼打字场景使用模拟文档界面，不表示软件会自动操作 Word；小鱼角色反馈来自实际渲染。
- DSH/API 段使用实际界面状态截图与模拟点击动画。
- 视觉仍为手动或逐轮附图，需要支持图片的模型，不宣称持续视频理解。

## 隐私与发布

不录桌面、任务栏、DSH 会话列表、其他对话标题或正文、私人路径和密钥。所有演示文字使用专用虚构内容。

软件为 Beta，模型和服务需自行配置。软件代码免费开源；第三方模型按各自许可使用，外部 API 可能收费。不使用未经证实的“全网首发”。
